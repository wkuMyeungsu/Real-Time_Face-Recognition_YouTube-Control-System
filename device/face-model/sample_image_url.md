# 테스트용 샘플 이미지

얼굴 감지 테스트에 쓴 이미지는 저장소에 넣지 않고, Edge Impulse 공개 프로젝트에서 찾아 쓴다.

| 항목 | 값 |
|---|---|
| 샘플 이름 | `37864.2u5qm900` |
| 위치 | Edge Impulse 공개 프로젝트 116394 → Data acquisition → Training |
| 주소 | https://studio.edgeimpulse.com/public/116394/latest/acquisition/training?page=1 |

## 찾아가는 방법

1. 위 주소를 연다. 공개 프로젝트라 로그인 없이 볼 수 있다.
2. **Training** 탭의 샘플 목록이 열린다.
3. 목록 위의 검색(필터) 칸에 `37864`를 입력하면 `37864.2u5qm900`만 남는다.
   검색 칸이 보이지 않으면 페이지를 넘기며 이름 열에서 `37864.2u5qm900`을 찾는다.
4. 샘플을 누르면 오른쪽에 이미지와 라벨(`face` 박스)이 보인다. 원본 파일은 샘플 메뉴(⋮)에서 내려받는다.

## 주의

- 실제 사람의 사진이므로 저장소에 커밋하지 않는다. 필요할 때 위 주소에서 받아 저장소 밖에 둔다.
